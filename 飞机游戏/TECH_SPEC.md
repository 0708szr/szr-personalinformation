# 飞机大战（Sky Strike）网页小游戏 — 技术规格文档

> **版本**: v1.0  
> **目标读者**: Solo Builder（独立开发者）  
> **技术栈**: HTML5 Canvas + Vanilla JavaScript + CSS3  
> **预计开发周期**: 3-5 天

---

## 一、项目概述

### 1.1 游戏简介
一款科技风格（Cyberpunk/Sci-Fi）的竖版飞机大战网页游戏。玩家操控战机在星空中穿梭，击败敌人、收集道具、挑战 Boss，体验爽快的弹幕射击玩法。

### 1.2 核心卖点
- **科技感视觉**：霓虹光效、粒子系统、HUD 界面、全息投影风格
- **多样化玩法**：普通关卡 + Boss 战 + 无尽模式 + 成就系统
- **丰富道具**：多重射击、护盾、激光、炸弹、僚机等
- **手感出色**：丝滑移动、打击反馈、屏幕震动
- **渐进难度**：从简单到地狱，敌人类型逐级解锁

### 1.3 参考游戏
- 雷霆战机（腾讯）
- 飞机大战（微信经典版）
- 凤凰战机（Phoenix HD）
- 傲气雄鹰（Sky Force）

## 二、技术选型

### 2.1 技术栈
| 类别 | 选型 | 说明 |
|------|------|------|
| 渲染 | HTML5 Canvas 2D | 2D 游戏首选，兼容性好 |
| 语言 | Vanilla JavaScript (ES6+) | 无需框架，轻量快速 |
| 样式 | CSS3 + 自定义动画 | 菜单、HUD 等 UI 层 |
| 音效 | Web Audio API | 合成音效，无需外部资源 |
| 存储 | localStorage | 存档、最高分、成就 |
| 图片 | 纯 Canvas 绘制 + 少量 CSS 渐变 | 减少资源依赖，solo 友好 |

> **为什么不用游戏引擎？**  
> 对于 solo builder，原生 Canvas 学习成本最低、调试最方便、打包体积最小。飞机大战逻辑不复杂，原生完全够用。

### 2.2 浏览器兼容
- Chrome 90+（推荐）
- Firefox 88+
- Safari 14+
- 移动端浏览器（触屏支持）

## 三、游戏核心玩法设计

### 3.1 基本操作
| 操作 | 桌面端 | 移动端 |
|------|--------|--------|
| 移动 | 鼠标拖动 / 方向键 / WASD | 手指拖动 |
| 射击 | 自动射击（默认开启） | 自动射击 |
| 释放炸弹 | 空格键 / 点击炸弹按钮 | 点击炸弹按钮 |
| 暂停 | ESC / P 键 / 暂停按钮 | 暂停按钮 |

### 3.2 游戏模式

#### 模式一：关卡模式（闯关）
- 共 **5 个大关**，每关末尾有 Boss
- 关卡递进：难度逐渐增加，敌人种类增多
- 通关后解锁下一关，同时解锁「无尽模式」对应关卡

#### 模式二：无尽模式
- 从第 1 波开始，无限刷怪
- 难度随波数递增
- 记录最高分，支持本地排行榜

#### 模式三：Boss Rush
- 连续挑战所有 Boss
- 每个 Boss 之间有短暂补给
- 记录通关时间

### 3.3 玩家战机系统

#### 属性
- **生命值（HP）**：初始 3 点，被击中扣 1 点，为 0 则游戏结束
- **护盾（Shield）**：道具获取，可抵挡 1 次伤害，有持续时间
- **炸弹（Bomb）**：初始 2 个，清屏伤害 + 无敌 2 秒
- **火力等级**：1-5 级，逐级增强子弹数量和威力

#### 战机皮肤（可选扩展）
- 初始战机：「猎鹰」
- 解锁战机：「雷霆」（通关第 3 关）、「幻影」（通关第 5 关）

### 3.4 敌人类型

| 敌人 | 血量 | 移动方式 | 攻击方式 | 出现关卡 | 得分 |
|------|------|----------|----------|----------|------|
| 小飞机（Scout） | 1 | 直线下降 | 无 | 1+ | 100 |
| 侦察机（Fighter） | 2 | 之字形 / 俯冲 | 单发子弹 | 1+ | 200 |
| 重型机（Heavy） | 5 | 缓慢前进 | 散射 3 发 | 2+ | 500 |
| 轰炸机（Bomber） | 8 | 缓慢前进 + 左右移动 | 投弹（抛物线） | 3+ | 800 |
| 精英机（Elite） | 10 | 追踪玩家 | 多发追踪弹 | 4+ | 1500 |
| 僚机无人机（Drone） | 1 | 环绕 Boss | 射击玩家 | Boss 战 | 300 |

### 3.5 道具系统

| 道具 | 图标风格 | 效果 | 持续时间 |
|------|----------|------|----------|
| 火力提升（Power Up） | 红色 P 字 | 火力等级 +1（最多 5 级） | 永久（死亡降 1 级） |
| 护盾（Shield） | 蓝色 S 字 | 获得一层护盾 | 15 秒 / 直到被击中 |
| 炸弹（Bomb） | 橙色 B 字 | 炸弹数量 +1（最多 5 个） | - |
| 激光（Laser） | 紫色 L 字 | 切换为激光武器，穿透伤害 | 10 秒 |
| 僚机（Wingman） | 绿色 W 字 | 召唤 2 架僚机辅助射击 | 15 秒 |
| 回血（HP） | 红心 | 生命值 +1（最多 5 点） | - |
| 金币（Coin） | 金色圆形 | 增加分数 | - |

### 3.6 得分系统
- 击杀敌人获得基础分
- 连击加成：连续击杀敌人，连击数越高，得分倍率越高（最高 x5）
- 拾取金币额外加分
- 关卡通关奖励分数
- 无伤通关有额外奖励

## 四、Boss 战设计（重点）

### 4.1 共有 5 个 Boss，每关 1 个

#### Boss 1：「守卫者」（Guardian）— 第 1 关
- **血量**：50
- **外观**：中型机甲，蓝色主色调
- **技能**：
  1. 普通射击：前方扇形 5 发子弹
  2. 旋转弹幕：360° 旋转发射子弹（慢速）
- **阶段**：单阶段
- **攻略要点**：躲避扇形弹，找到旋转弹幕的空隙

#### Boss 2：「烈焰」（Inferno）— 第 2 关
- **血量**：100
- **外观**：红色火焰涂装战机
- **技能**：
  1. 火焰喷射：前方锥形火焰区域（持续伤害）
  2. 导弹齐射：发射 4 发追踪导弹
  3. 召唤小兵：召唤 3 架小飞机
- **阶段**：2 阶段（血量 50% 后进入二阶段，攻击频率加快）
- **攻略要点**：注意导弹追踪，及时清理小兵

#### Boss 3：「幽灵」（Phantom）— 第 3 关
- **血量**：150
- **外观**：紫色隐形战机，半透明效果
- **技能**：
  1. 瞬移闪现：随机位置出现并射击
  2. 环形弹幕：大范围环形子弹
  3. 激光扫射：左右扫描的激光束
- **阶段**：3 阶段（每 50 血一阶段，技能组合不同）
- **攻略要点**：预判瞬移位置，激光扫射时找安全区

#### Boss 4：「泰坦」（Titan）— 第 4 关
- **血量**：250
- **外观**：巨型重甲战舰，多炮塔
- **技能**：
  1. 多炮塔齐射：左右中三路同时射击
  2. 轰炸模式：从空中投下大量炸弹
  3. 冲撞攻击：快速向下冲撞
  4. 召唤僚机：左右各 2 架无人机僚机
- **阶段**：2 阶段（血量 40% 进入狂暴模式，攻击翻倍）
- **攻略要点**：优先打掉僚机，躲避冲撞

#### Boss 5：「终极 Boss — 湮灭」（Annihilation）— 第 5 关
- **血量**：500
- **外观**：超级巨型战舰，多段变形，核心暴露机制
- **技能**（4 个阶段）：
  - **第一阶段（100%-75%）**：双翼炮塔 + 普通弹幕
  - **第二阶段（75%-50%）**：展开双翼，激光阵列 + 追踪导弹
  - **第三阶段（50%-25%）**：核心暴露，召唤大量小兵 + 全屏弹幕
  - **第四阶段（25%-0%）**：狂暴模式，旋转激光 + 随机轰炸 + 冲撞
- **攻略要点**：每个阶段打法不同，核心暴露时全力输出，注意阶段转换时的全屏攻击

### 4.2 Boss 战通用机制
- **血条显示**：屏幕顶部 Boss 血条，带名称
- **阶段转换提示**：文字提示 + 屏幕闪红 + 短暂无敌
- **掉落奖励**：击败 Boss 必掉火力 + 护盾 + 炸弹
- **无敌时间**：Boss 出场有 2 秒无敌，阶段转换有 1 秒无敌

### 6.2 核心类设计

#### Game 类（游戏主控）
```javascript
class Game {
  constructor() {}
  init() {}          // 初始化
  start() {}         // 开始游戏
  pause() {}         // 暂停
  resume() {}        // 继续
  gameOver() {}      // 游戏结束
  update(dt) {}      // 逻辑更新
  render() {}        // 渲染
  loadLevel(n) {}    // 加载关卡
}
```

#### 实体基类
```javascript
class Entity {
  x, y, width, height, speed, active
  update(dt) {}
  draw(ctx) {}
  collidesWith(other) {}  // AABB 碰撞检测
}
```

### 6.3 游戏状态机
```
MENU → PLAYING → PAUSED → PLAYING
         ↓
       GAME_OVER → MENU
         ↓
       LEVEL_COMPLETE → NEXT_LEVEL / MENU
```

### 6.4 碰撞检测方案
- **AABB 碰撞**（轴对齐包围盒）：玩家 vs 敌人、子弹 vs 敌人、玩家 vs 道具
- **圆形碰撞**：爆炸范围判定、Boss 技能范围
- **优化**：只检测屏幕内的实体，分区管理减少计算量

### 6.5 性能优化策略
1. **对象池**：子弹、粒子、敌人频繁创建销毁，使用对象池复用
2. **离屏渲染**：背景星空、重复图案预渲染到离屏 Canvas
3. **分层渲染**：背景层、游戏层、UI 层分离
4. **节流更新**：远处的粒子减少更新频率
5. **帧率控制**：requestAnimationFrame + 固定时间步长更新

### 7.1 关卡结构
每关 = 若干波敌人 + Boss 战  
波与波之间有短暂间隔，波数越多越难

### 7.2 敌人波次生成逻辑
- 第 1 关：小飞机为主，少量侦察机
- 第 2 关：侦察机 + 重型机
- 第 3 关：重型机 + 轰炸机
- 第 4 关：全类型混合，精英机出现
- 第 5 关：高密度敌潮 + 精英机频繁出现

## 八、音效设计（Web Audio API 合成）

### 8.1 音效列表
| 音效 | 描述 | 触发时机 |
|------|------|----------|
| 射击声 | 短促的 "嘀" 声 | 玩家射击 |
| 爆炸声 | 低沉爆炸声 | 敌人爆炸 |
| 拾取声 | 清脆的 "叮" 声 | 拾取道具 |
| 受击声 | 沉闷的 "咚" 声 | 玩家被击中 |
| Boss 出场 | 警报声 + 低沉轰鸣 | Boss 出现时 |
| 激光声 | 持续的 "嗡" 声 | 激光武器持续射击 |
| 炸弹声 | 巨响 + 余音 | 释放炸弹 |
| 背景音乐 | 循环电子乐 | 游戏进行中 |

### 8.2 实现方式
- 使用 OscillatorNode + GainNode 合成简单音效
- 背景音乐用循环的短旋律序列
- 提供音效开关（默认开启）

## 九、UI 页面清单

### 9.1 页面 / 弹窗列表
1. **主菜单**（Main Menu）：游戏标题、各模式入口、设置、排行榜
2. **战机选择**（Aircraft Select）：选择战机（有解锁条件）
3. **关卡选择**（Level Select）：选择关卡（有解锁条件）
4. **游戏 HUD**：游戏内信息显示
5. **暂停界面**（Pause Menu）：继续、重开、返回主菜单
6. **游戏结束**（Game Over）：得分、历史最高、重开、返回
7. **关卡通关**（Level Complete）：评价、奖励、下一关
8. **Boss 警告**（Boss Warning）：Boss 出场前的警告动画
9. **排行榜**（Leaderboard）：本地最高分排行
10. **设置**（Settings）：音效开关、难度选择、操作说明

### 9.2 科技风 UI 规范
- 字体：等宽字体 + 数字字体（如 `Courier New`, `Orbitron` 从 Google Fonts 引入）
- 按钮：发光边框 + 渐变填充 + hover 时亮度增加
- 面板：半透明深色背景 + 霓虹边框 + 角落装饰线
- 进度条：渐变填充 + 发光效果
- 文字：带轻微发光效果（text-shadow）

## 十一、关键技术难点与解决方案

### 11.1 弹幕密度高时的性能
- **问题**：大量子弹同时存在可能掉帧
- **方案**：对象池复用子弹 + 分区碰撞检测 + 限制最大子弹数

### 11.2 Boss 多阶段状态管理
- **问题**：Boss 技能多、阶段切换复杂
- **方案**：状态机模式，每个阶段独立的行为函数，切换时重置

### 11.3 科技风视觉效果
- **问题**：纯 Canvas 绘制如何做出科技感
- **方案**：
  - 使用 `ctx.shadowBlur` + `ctx.shadowColor` 做发光效果
  - 粒子系统做拖尾和爆炸
  - 背景用径向渐变 + 随机星星点
  - UI 用 CSS 的 `box-shadow` 和 `text-shadow` 做发光

### 11.4 碰撞检测精度
- **问题**：快速移动的子弹可能穿透敌人
- **方案**：使用连续碰撞检测（CCD），或者提高更新频率，或者简单地增加子弹碰撞体积

## 十三、给 Solo Builder 的建议

1. **先做最小可用版本**：先实现玩家移动 + 射击 + 简单敌人 + 碰撞，能玩了再加内容
2. **多用 console.log 调试**：Canvas 游戏调试主要靠 log 和视觉观察
3. **参数配成常量**：所有数值（速度、血量、得分等）放在 `constants.js`，方便调平衡
4. **每完成一个功能就测试**：不要堆到最后一起测
5. **善用 Chrome DevTools**：Performance 面板看帧率，Canvas 面板调试绘制
6. **参考开源项目**：GitHub 上搜 "html5 plane shooter game" 有很多参考
